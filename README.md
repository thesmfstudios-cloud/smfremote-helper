# Utility

Private utility collection for SMF workflows and reusable PC automation.

## Utilities

- `utilities/smf-remote/` - reusable Windows remote actions for Chrome, YouTube, Gmail, Drive, WhatsApp, Razorpay, AWS Billing, Desktop, and studio-work.

## Sync rule

Local changes are committed in this repository. Run `sync.ps1` to push changes to `thesmfstudios-cloud/smfremote-helper`. Future ChatGPT-driven utility changes should update this repository alongside the local working copy.

## Safety

Runtime history/log files, secrets, tokens, and machine-specific credentials are not committed.
